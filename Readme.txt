================================================================
 YouTube -> MP3 — инструкция
================================================================

ЧТО ЭТО
-------
Программа скачивает аудио из YouTube и сохраняет его в mp3.

Два способа работы:
  1) Обычный: двойной клик по YouTubeMP3.exe (окно программы).
  2) Командный: через командную строку — удобно для автоматизации
     и для агентов (Codex и т.п.).

БЫСТРЫЙ СТАРТ (GUI)
-------------------
1. Запустите YouTubeMP3.exe.
2. Вставьте одну или несколько ссылок YouTube (по одной в строке).
3. Укажите папку, куда сохранить mp3 (кнопка "Обзор...").
4. Выберите качество: 320 / 192 / 128 kbps (по умолчанию 192).
5. Нажмите "Скачать MP3" и дождитесь надписи "Готово".

Галочка "Скачивать плейлист целиком": включите её, если ссылка —
плейлист и нужны все видео из него. Без неё качается только
конкретное видео.

КОМАНДНЫЙ РЕЖИМ (для Codex и автоматизации)
-------------------------------------------
Формат команды (из папки программы, нужен установленный Python):

  python youtube_mp3.py --url ССЫЛКА --out ПАПКА --quality 192

Параметры:
  --url      ссылка YouTube (можно указывать несколько раз,
             можно передавать несколько ссылок подряд);
  --out      папка для mp3 (по умолчанию ~\Music);
  --quality  320 / 192 / 128 kbps (по умолчанию 192);
  --playlist скачать плейлист целиком (без этого — одно видео).

Примеры:

  python youtube_mp3.py --url "https://www.youtube.com/watch?v=jNQXAC9IVRw" --out D:\Music
  python youtube_mp3.py -u ССЫЛКА1 -u ССЫЛКА2 -o D:\Music -q 320
  python youtube_mp3.py --url ССЫЛКА_ПЛЕЙЛИСТА --playlist --out D:\Music

Коды выхода: 0 — всё скачано, 1 — были ошибки, 2 — не установлен
модуль yt-dlp. Весь вывод командного режима — на английском.

ФАЙЛЫ
-----
  YouTubeMP3.exe   сама программа (окно);
  youtube_mp3.py   исходник: окно + командный режим;
  ffmpeg\          ffmpeg.exe и ffprobe.exe — нужны для конвертации
                   в mp3, не удаляйте эту папку;
  AGENTS.md        техническая инструкция для агентов (Codex).

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
-----------------------
- Ошибки вида "no formats" / "unable to extract": YouTube обновил
  защиту, нужно обновить yt-dlp командой:
      python -m pip install -U yt-dlp
- mp3 не создаётся (остаётся файл .webm/.m4a): проверьте, что рядом
  с программой есть папка ffmpeg с ffmpeg.exe.
- "Скачалось 0 из 1" и видео недоступно: возможно, видео частное,
  удалено или ограничено по региону.

КАК ПЕРЕСОБРАТЬ EXE (если меняли youtube_mp3.py)
------------------------------------------------
  python -m PyInstaller --onefile --windowed --name YouTubeMP3 ^
      --distpath . --workpath build --specpath . --clean --noconfirm ^
      youtube_mp3.py

(выполнять из папки программы).

Замечание: скачивайте аудио только для личного использования и
уважайте авторские права авторов видео.
